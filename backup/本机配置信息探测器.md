### 主要检测维度

| 类别 | 检测项目与内容 |
| --- | --- |
| **系统与浏览器** | 操作系统类型及版本、浏览器内核与版本架构（基于 `ua-parser-js`） |

### 技术实现与规范透明

该工具基于现代 Web 标准 API（如 WebGL、Screen、Navigator、Storage、MediaDevices、WebRTC 等）构建。它不仅提供参数展示，还对现代浏览器的安全与隐私限制做了清晰说明：

* **内存封顶说明**：受限于现代浏览器出于防指纹追踪的隐私保护策略，`deviceMemory` 接口通常只返回阶梯式估算值（常见上限为 8GB）。
* **接口兼容提示**：如遇 Battery Status API 废弃或 WebRTC 隐私限制，工具会清晰标注原因，而非报错崩溃。
