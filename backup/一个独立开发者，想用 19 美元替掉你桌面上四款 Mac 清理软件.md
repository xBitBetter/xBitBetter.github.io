我关注 Tw93 挺久了。早年在 Pake、MiaoYan 那一串小工具里就见过这个名字，后来他做 Mole，先是命令行版本，开源，命令叫 `mo`，不少人从那时候就在用。今年 GUI 版本出来，他把它做成了正式的 Mac 原生应用，我特意去官网（mole.fit/zh）和 GitHub 仓库对着看了一遍，想弄清楚一件事，19 美元买断，号称能替掉 CleanMyMac、AppCleaner、DaisyDisk、iStat Menus 这四样东西，到底是不是吹的。

先把结论放这儿。对大多数普通 Mac 用户，它够用了，而且价格确实良心。我的判断是，它把四款软件里最常做的那几件事压进了一个界面，普通用户的日常够覆盖，最专业的那部分覆盖不了。

## 它把什么装进了一个 App

Mole 把功能排成了"五颗星球"，名字起得有点中二，但对应的事很实在。地球是清理，扫缓存、日志、开发工具构建残留，十类项目按影响排序，可再生缓存在最前面，而且可以"先看后删"，不想动的加进保护清单。火星管软件，检查更新、彻底卸载、管登录项和后台项，卸载时会把残留一起审一遍。水星做优化，修 Quick Look、清元数据、重置系统服务。木星是磁盘分析，整盘树形图，逐层展开找大文件。太阳是状态，CPU、内存、GPU、温度、风扇、电量实时看，菜单栏还能常驻几个指标。

我比较在意两处设计。一处是清理和分析都在本机跑，不上传，网页里明写了"扫描清理本机完成，不上传"，这对一个要翻你磁盘的工具很重要。另一处是有风险的操作会自己跳过并说原因，比如重置系统服务这种事，它没有偷偷替你做，做完还列一份结果和跳过清单。这种克制在一个清理软件里不多见，多数同类会先把条打满，等你后悔。

## 19 美元贵不贵

价格我反复确认过几次，因为它的优惠活动历史上改过。当前官网写的是 19 美元买断，授权 2 台 Mac，永久更新，14 天免费试用，14 天退款保证，还能切 CNY 用微信付。

对比它想替掉的几款，CleanMyMac 走订阅，一年下来比 19 美元贵出不少；DaisyDisk 和 iStat Menus 都是单次买断但单价也不低，加起来远超 19。所以"一个价钱替四个"在账面上成立，前提是你要的只是这四款里最常被用到的那部分。我没法替你确认你个人的使用深度，这点下面说。

## 它替不掉的那部分

必须说清楚，Mole 不是把四款软件各自最强的地方都吃下来了。DaisyDisk 的树形图交互更细，iStat Menus 的菜单栏自定义和历史曲线更老练，CleanMyMac 的卸载和某些维护项更全。Mole 的木星和太阳做得顺手，但论专业深度，它更像"刚好够普通用户用"，不是"比每一款都强"。

还有平台。它只要 Mac，系统要求 macOS 14 以上，没有 Windows 版，也没有 iOS、Android、Web。官网评论区里一堆人喊 Windows 版，到现在没出。如果你主要用 Windows，这篇跟你无关。


## 谁适合，谁先等等

适合的是 Mac 上积了一堆开发构建残留和缓存、嫌开四五个工具麻烦、不想年年交订阅的普通用户。19 美元、两只机器、永久更新，这个组合对这类人很划算。

可以先等等的，是那些对磁盘分析或系统监控有专业要求、本来就在用 DaisyDisk 或 iStat Menus 高级功能的人，或者你主要不用 Mac。另外，如果你特别在意某一项能力的极致深度，先想清楚 Mole 那颗星球能不能覆盖你八成的使用，再决定要不要换。

GitHub 上那 63.5k 星和 121 位贡献者能说明社区买账，但星标不等于适合你。它替不掉的那部分，才是你做决定前真正该想清楚的地方。
