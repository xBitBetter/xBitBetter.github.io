本机配置信息探测器

纯前端实现 · 基于浏览器标准 API 实时读取本机/浏览器配置 · 数据不上传、全部本地计算

说明：浏览器出于隐私保护，仅能读取部分本机信息（如 CPU 核心数、内存为近似值、GPU 经 WebGL 暴露的渲染器字符串）。 检测逻辑复用了开源库 ua-parser-js（MIT），其余基于 WebGL / Screen / Navigator / Network Information / Storage / MediaDevices 等标准 API。

常见问题

这个工具会读取并上传我的数据吗？

不会。全部检测都在你本机的浏览器内完成，不发起任何网络请求，配置信息不会上传到任何服务器，可放心使用。

它能检测到哪些本机信息？

覆盖浏览器与操作系统、CPU 逻辑核心数与架构、内存估算、屏幕分辨率与色彩深度、GPU 渲染器型号、网络类型与带宽、电池、存储配额、摄像头/麦克风等媒体设备，以及已安装字体的抽样检测。

为什么内存只显示到 8GB 上限、数值不够准确？

出于隐私保护，浏览器对 deviceMemory 接口有上限限制（通常封顶 8GB），且返回的是粗略估算值，并非真实物理内存容量。

为什么电池状态显示「不支持」？

Battery Status API 已在 Chrome 等现代浏览器中被移除，绝大多数环境下无法读取电池信息，显示「不支持」属于正常现象，并非工具故障。

支持哪些浏览器？本地 IP 一定能获取到吗？

任何现代浏览器（Chrome、Edge、Firefox、Safari 等）均可正常使用。本地 IP 通过 WebRTC 候选地址获取，部分浏览器出于隐私会限制该项，可能为空或获取不到，属正常情况。
